## Reproduction and release gates

1. **External AI/research blocked:** start Brain with all cloud keys absent and OLLAMA_ENABLED=false; POST `/brain/chat` with `{"message":"How can I save energy?"}`. Expected: 503, not fabricated analysis. Configure a provider/key/model and test a sustainability query, a Tavily fact check and an OpenAlex research query. Include returned source URLs and independently inspect supporting papers.
2. **Missing corpus:** search checkout for `*.pdf`; no 11-paper corpus is present. Set RESEARCH_PDF_DIR to supplied, licensed readable PDFs and restart Brain. Validate page metadata, duplicate ingestion, corrupt/encrypted files and retrieval before accepting paper-grounded answers.
3. **Hardware GPS:** install APK on Android 13+, complete onboarding and permit while-in-use location. Relaunch: no repeated prompt. Walk, cycle and travel above 25km/h; stop 3 minutes. Verify filtered distance, zero emitted carbon for walk/cycle, chosen high-speed mode, one trip after reconnect. Background 30 minutes and inspect service, battery and permission revocation. Kill/relaunch during a trip: in-progress capture is not persisted.
4. **Route/carpool limitations:** search a real destination and compare returned polylines with OSM roads. Do not call road-distance metro estimates actual transit routing. Post a driver whose route passes within 2km but pickup is >5km away: the PostGIS acceptance test requires it to appear through corridor matching. Pickup distance is a straight-line estimate, not a walking itinerary.
5. **Disaster/shelter/SOS blocked:** omit MUNICIPAL_SHELTER_FEED_URL; shelter request returns 503. SOS stores coordinates/address/battery; it does not contact authorities or trusted contacts. Do not advertise emergency delivery. A precipitation forecast is not a flash-flood warning.
6. **Tracker history gap:** log different categories on multiple devices; current frontend category bars describe local baseline shares and do not fully reconstruct remote historical category deltas.
7. **Provider coverage:** scan an Open Food Facts product with no environmental grade/Agribalyse data. Expected: unavailable fields, not invented scores. Missing lifecycle/alternatives remain a coverage limitation.
8. **58-tool audit:** `backend/tool-handler-map.json` maps every tool to real gateway handlers; `frontend/assets/feature_catalog.json` inventories consumer labels/inputs. Authenticate and invoke each with valid fixture records/provider configuration; record payload/status/schema and downstream side effects. Current smoke proves authentication for all 58, not successful operations for all 58.
9. **Offline ledger:** disconnect gateway; claim habit/log completed trip; restart app and reconnect with the same account. Outbox should survive, drain once and reconcile server point balance. Retrying one trip's client_id must return the existing row without awarding more points. Habit claims older than seven days need manual reconciliation; this is a release gate.

## Configuration and execution

Do not commit keys or real user data. Required gateway environment: DATABASE_URL (PostGIS PostgreSQL), JWT_SECRET, BRAIN_URL=http://127.0.0.1:8000, GATEWAY_PORT=3000. Apply migrations in filename order with psql ON_ERROR_STOP. Existing repository has two 002 migration filenames; this workflow applies both explicitly, not SQLx's versioned migrator. Existing deployments should apply only the new 003 migration after confirming previous migrations already ran.

Brain environment: GEMINI_API_KEY/GEMINI_MODEL, GROQ_API_KEY, OLLAMA_ENABLED/OLLAMA_BASE_URL/OLLAMA_MODEL, TAVILY_API_KEY, OPENALEX_API_KEY and optional RESEARCH_PDF_DIR. The old requested Gemini 1.5 model should not be forced; GEMINI_MODEL is configurable. Pin an available model for your account. Brain requirements include pypdf.

Flutter endpoint: `flutter build apk --dart-define=API_BASE_URL=http://10.0.2.2:3000` for Android emulator; use your reachable LAN/HTTPS endpoint for a physical device. Web uses localhost by default. No Android SDK or physical device was available for this audit.

Optional shelter feed: MUNICIPAL_SHELTER_FEED_URL should return a trusted array containing name, lat, lng, isOpen and capacity/status metadata. No shelter data is manufactured when absent.

Run Brain `PYTHONPATH=. pytest -q tests`; gateway `cargo test --target x86_64-unknown-linux-gnu`; frontend `flutter test` and `flutter build web --release`. `.github/workflows/ecosystem-audit.yml` additionally runs the disposable PostGIS acceptance checks.

External data attribution: OpenStreetMap contributors; OSRM road routing; Open-Meteo weather and CAMS air-quality forecasts; Open Food Facts/Agribalyse metadata; Tavily search results; OpenAlex bibliographic metadata. Provider results are model/database evidence, not independent verification. Consult provider quotas and terms before production deployment.
